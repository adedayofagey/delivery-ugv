# dvx_ugv_v2_0_description

Robot description for **dvx_ugv_v2_0**, generated by URDF Forge.
REP 103 conventions: Z-up, metres, kilograms, radians.

## Build

```bash
cd ~/ros2_ws/src && cp -r /path/to/dvx_ugv_v2_0_description .
cd ~/ros2_ws && rosdep install --from-paths src -y --ignore-src
colcon build --packages-select dvx_ugv_v2_0_description && source install/setup.bash
```

## Run

`ros2 launch dvx_ugv_v2_0_description display.launch.py` shows the model in RViz with joint sliders.

| Target | Distribution | Simulator launch |
| --- | --- | --- |
| `humble-fortress` | ROS 2 Humble · Gazebo Fortress | `ros2 launch dvx_ugv_v2_0_description gazebo_humble-fortress.launch.py` |

## Layout

- `urdf/dvx_ugv_v2_0.urdf.xacro`: the source of truth. `xacro dvx_ugv_v2_0.urdf.xacro sim:=<target>` (default `humble-fortress`).
- `urdf/dvx_ugv_v2_0.<target>.urdf`: pre-expanded URDF per target, for tools that cannot run xacro.
- `sdf/dvx_ugv_v2_0/`: standalone SDF model.
- `meshes/`: binary STL meshes.
- `config/controllers.yaml`: ros2_control controllers. `config/gz_bridge_<target>.yaml`: ROS <-> Gazebo topics.
- `worlds/`: an empty world with the physics, sensors, IMU, contact and force-torque systems loaded.

## Notes

- Mesh URIs use `package://dvx_ugv_v2_0_description/...`. The launch files add the install share
  directory to the simulator's resource path so Gazebo can resolve them.
- Inertias were integrated over the mesh geometry for a solid of uniform density. Check any link
  the editor flagged as not watertight.
